通过 "agent" 工具把任务委派给一次性子代理，参数只有 template 与 task。

- template：注册表 agent id。内置模板：agent_explorer（代码库探索）、agent_planner（任务规划）、agent_coder（编码实现）、agent_reviewer（对抗性审查）；也可使用用户自定义的 agent id。
- task：完整、自包含的任务描述。子代理只能看到这段内容，不会继承当前对话、上下文或你的推理过程，必须把目标、范围、约束、验收标准写清楚。
- cwd：可选，默认当前会话工作目录。

子代理在自己的隐藏会话中运行，完成后返回最终报告。同一轮发起多个 agent 调用会并发执行（上限 4），适合互不依赖的独立子任务；有先后依赖时请分轮派发。
